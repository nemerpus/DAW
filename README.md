# DAW

Repositorio de prácticas y materiales del ciclo de Desarrollo de Aplicaciones Web.

## Contenido

La carpeta `DWEC/` reúne teoría, ejercicios y entregas de Desarrollo Web en Entorno Cliente. Las actividades incluyen páginas HTML, JavaScript, documentos de trabajo y capturas de sus resultados.

## Uso

Los ejercicios web se ejecutan abriendo su archivo HTML en un navegador. Este repositorio se conserva como archivo de aprendizaje y entregas; no representa una aplicación única desplegable.
